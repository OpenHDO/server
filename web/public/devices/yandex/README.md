# Device illustrations

Original on/off PNG illustrations from the official
[Yandex Smart Home device catalogue](https://yandex.ru/dev/dialogs/smart-home/doc/ru/concepts/device-types).
The illustrations are reproduced unchanged. The catalogue in
`python/openhdo_server/device_types.json` records the documentation page for each
device type. These assets are Yandex's illustrations, not original HDO artwork;
this directory does not grant a separate licence to them.
