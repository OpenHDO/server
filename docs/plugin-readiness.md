# Готовность системы плагинов

Проверено на текущем сервере HDO. Статус: рабочая основа для доверенных
плагинов, API v1 пока стоит считать предварительным.

| Часть | Готовность |
| --- | --- |
| Python SDK | Контекст, разрешения, приватный SQLite store, миграции, события, задачи и очистка ресурсов работают. Общий ProviderError исключает импорт внутренних ошибок сервера. |
| TypeScript SDK | Типы собираются; React предоставляется хостом, модули и расширения освобождаются при отключении. Есть authenticated request, уведомления, переводы и стандартная карточка устройства. |
| Загрузчик | Установка .hdop, включение, отключение, удаление, зависимости и откат неудачного обновления покрыты проверками. |
| Провайдеры | Импорт, команды, автоматический опрос, личные формы OAuth и сохранение локальных ID/комнат подключены к текущему Devices. |
| Панель | Раздел «Плагины», установка пакета, управление состоянием и настройки работают в дизайне остальных разделов. Ошибки и успехи показываются поверх интерфейса. |
| Темы и языки | Загрузка и очистка доступны; замена существующего языка требует явного replace. Одновременное расширение одного языка несколькими плагинами пока ограничено. |
| Widgets / deviceModels / flowNodes | Реестры доступны в SDK. Автоматическое использование текущими встроенными Dashboard, Devices и Logic ещё не подключено. |
| CLI | init, build, validate, pack и воспроизводимые архивы с контрольными суммами работают; тесты утилиты проходят. |
| CI / публикация | Шаблон workflow присутствует. Выпуск нового пакета Яндекса в GitHub в рамках этой задачи не выполнялся. |
| Изоляция и подписи | Плагины исполняются с правами процесса HDO. Контрольные суммы не заменяют подпись автора; sandbox и проверка издателя отсутствуют. |
| Каталог / обновления | Marketplace, автоматическое получение обновлений и установка Python-зависимостей отсутствуют. |

## Проверки

Проверены тесты сервера, жизненного цикла плагинов, CLI, модели Python SDK,
реестров панели и сборка TypeScript SDK. Для Яндекса отдельно проверены
авторизация, CSRF/роли, скрытие секрета, команды, конкурентность запросов,
состояния online/offline, цвета, миграция интеграций и комнат.

Проверки адаптера Яндекса выполняются при соседнем checkout `server-yandex`.
В отдельном checkout сервера они пропускаются; сервер больше не импортирует
Яндекс для запуска или базовых тестов.

Облачные ответы проверялись через mock transport; настоящий вход с новым
личным OAuth-приложением должен проверить владелец аккаунта.

Следующие важные работы: стабилизировать интерфейс сервиса устройств вместо
прямого доступа провайдера к менеджеру, подключить потребителей оставшихся
UI-расширений, добавить версионирование совместимости SDK и подписи пакетов.

См. [SDK и формат пакета](plugins.md) и [плагин Яндекса](../../server-yandex/README.md).
