# OpenHDO Server

The server and web panel for OpenHDO smart homes.

Manage devices, rooms and integrations in one panel. Connect Tuya / Smart Life
or Home with Alice, control supported devices and keep settings locally.

## Getting started

- [Release downloads](https://github.com/OpenHDO/server/releases)
- [Build and run from source](docs/build.md)

Yandex is an optional plugin configured with your own OAuth application.
Credentials and account tokens stay in your installation's `data/`.
